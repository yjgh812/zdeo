## 一、核心结论（先讲答案）

1. **IC>0.05 在此框架内不可达**——0.0412 是"Alpha158 量价特征 + GBDT + 次日收益标签"的物理天花板。五轮 IC 优化（W1-W5）全部证明加法/集成/特征工程无效。
2. **IC 目标本身是伪命题**——组合层验证（W6-W9）证明 IC=0.04 的信号经过**多种子集成 + TopK20 精选**，在保守口径（T+1 开盘成交、含成本、含涨跌停约束）下 9 个月创造 **+14.4% 超额收益**（vs csi300 等权）。
3. **决定性技术是多种子 Rank 平均**——单种子信号随机性导致组合收益在 ±5% 间波动，5 种子集成后稳定为正。

## 三、最终配置

```
特征     : Alpha158（113 量价特征，RobustZScoreNorm + Fillna）

集成     : 5 个随机种子（1/7/42/123/999）Rank 平均
标签     : Ref($close,-1)/$close-1（次日收益）
训练     : 5 年滚动（每季度重训）

成交     : T+1 开盘价（信号次日执行，无前视）
成本     : 买入 5bp + 卖出 10bp + 最低 5 元，一手 100 股
涨跌停   : 9.5% 阈值，涨停禁买跌停禁卖
```

## 四、诚实保留项（未消除的不确定性）

1. **样本窗口有限**：9 个月（2024Q4~2025Q2），单一行情周期，跨牛熊验证未做
2. **Q2 单季超额为负**（-0.57%）：集成信号在 2025Q2 弱于等权，模型存在时段退化风险
3. **回撤 -17.8%**：进攻型策略，最大回撤显著，实盘需接受或叠加组合级风控
4. **benchmark 为等权**：与沪深300指数（市值加权）存在差异
5. **数据源**：qlib bin 无指数/估值数据，特征空间受限
