# 屠龙系统·A股（沪深两市，不含北交所）上涨股票AI画像Agent自主执行计划书
**执行主体**：PortraitAgent（画像师代理，继承BaseAgent基类）
**覆盖市场**：沪深两市全部A股（含主板、创业板、科创板），**不含北京证券交易所挂牌标的**
**适配系统**：屠龙系统
**冷启动时效**：单交易日内完成全量基线落地，T+1日自动进入影子运行
**执行模式**：基线能力一次性全量部署生效，增量能力按周期自主迭代优化
**核心遵循**：屠龙系统「复盘→涨跌停归因→回头看→整改→迭代」闭环规范

## 一、Agent定位与执行总则
### 1.1 核心定位
PortraitAgent是屠龙多Agent架构中独立的特征建模与评分输出节点，**专门针对沪深A股（不含北交所）标的**构建上涨特征画像，不侵入核心交易、风控、清算逻辑，通过EventBus消息总线与系统柔性交互。
核心职能是对全市场A股进行多维度上涨特征建模，输出可解释的上涨概率与五维归因，为AnalystAgent提供选股增强信号，为RiskAgent提供风险标签，为ReviewAgent提供归因输入，驱动全链路闭环迭代。

### 1.2 标的范围界定
本Agent覆盖的股票池基础范围：
1. **纳入范围**：上海证券交易所、深圳证券交易所上市的全部A股，包含主板、创业板、科创板标的；
2. **剔除范围**：北京证券交易所所有挂牌股票、ST/*ST/*ST摘牌整理期股票、上市不满60个交易日的新股、停牌或连续无成交标的；
3. **优选范围**：结合屠龙系统策略偏好，优先覆盖中小盘、创业板标的，叠加股价≤20元的价格约束。

### 1.3 核心目标
1. 短期：一次性落地基线画像能力，沪深A股样本外RankIC≥0.03，每日Top20股票5日上涨命中率≥55%，为系统贡献≥10%年化超额收益；
2. 中期：通过自主迭代升级至进阶模型，RankIC≥0.05，年化超额收益≥20%；
3. 长期：实现多场景、多周期A股上涨画像全覆盖，支撑系统80%选股胜率、200%年化收益目标。

### 1.4 执行原则
1. **能落地的一次性全量落地**：基线特征、模型、接口、配置、校验逻辑全部一次性部署完成，单日内跑通全链路，不拆分人工阶段；
2. **增量能力周期化自动迭代**：需要数据积累、效果验证的进阶能力，按固定调度周期自主执行，无需人工触发；
3. **校验前置，失败自动降级**：每一步执行内置校验函数，不达标自动走异常分支，优先保障主系统稳定，不影响原有策略运行；
4. **全程可追溯，版本可回滚**：所有模型、特征、配置均版本化管理，异常一键回滚至上一稳定版本，所有操作留痕可审计。

### 1.5 Agent权限边界
#### 可自主操作
- 自身模块内的A股特征计算、模型训练、版本管理、配置调整（评分权重±5%范围内）；
- 订阅/发布约定的消息频道，调用数据中心开放的A股数据接口；
- 触发自身的降级、回滚、停用操作；
- 向ReviewAgent输出A股标的归因与优化建议。

#### 禁止操作
- 修改屠龙系统核心交易、风控、清算逻辑；
- 修改其他Agent的代码、配置、数据；
- 突破系统A股股票池规则、仓位限制、止损规则；
- 未经校验直接向实盘输出交易指令；
- 引入北交所标的及相关数据进入画像计算。
