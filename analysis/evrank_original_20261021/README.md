## 管线升级（主人令 20261102「选股方法要连通复盘结果和消息面情况」）

原版方法从"纯价量历史战绩"升级为四段管线，两处新连接已落地：

```
池子生成(复盘·行业层: 主线判别器强方向) → EV历史战绩裁决 → 复盘对齐标注 → 消息面验证层 → 呈报
```

1. **复盘对齐标注器** = `analysis/candidate_review_layer.py`：逐票标注[所属行业|是否主线|市场相位]，真源=主线判别器(breakout_mainline_latest)+方向普查(广度→活跃/中性/防御)。首跑(20261030数据)：晨令5只=3主线(瑞丰/仙琚/九州通)+2次线交运(中国外运/宁沪高速)；市场相位=防御(涨/跌0.03)。
2. **消息面验证层** = 自动化合同第1.5步：逐票 MCP 新闻扫描，硬雷(立案/退市/处罚/暴雷/停牌)否决、软雷(减持/质押/旧闻)警告呈报。首扫(20261101夜)：5只全无硬雷；软雷两处在案(仙琚吕良丰等减持/宁沪9-4国资疑云旧闻)。
3. 主线外入选(如次线交运)不拦截——次线本就是池子设计的合法成员，仅标注供主人知情。
