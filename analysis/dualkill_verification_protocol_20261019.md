## 二、四条建议判定标准（第二块，主人细化版）

**建议1：持有/卖出原因分层+卖出反事实**
- 每格 n≥30 才下结论。若2026亏损集中于"持有≤2天"和"趋势走坏卖出"格，且趋势卖出后20日超额>0、最大浮盈保留率低 → 根因成立。
- 实验：仅对"趋势走坏卖出"加最小持有3/5日或收盘确认；**不延迟-8%硬止损**。
- 成功判据：胜率≥+2pp、盈亏比≥1.1、Top5%右尾保留≥95%；失败：右尾<95%或盈亏比仍<1 → 不接线。
- ⚠️ 撞线注记：延迟趋势卖出撞主人 2026-10-09 裁决（判定须真、卖早没关系），回测对照仅为**呈报证据**，接线须主人单独批准。

**建议2：18闸门消融+时点审计**
- 审计每条闸门输入时点。重点"价格>30不买"：若用T+1开盘价，统计"信号日<30、次日高开>30被拒"比例 2026 是否升高；被拒组按行业/市值/vr120/gap 匹配成交组比20日超额。18条 leave-one-gate-out，FDR q<0.1。
- 判定：1-2条闸门被拒票后续超额为正、移除后2026胜率+2~4pp且右尾不降 → 改"排序惩罚/仓位缩放"；消融无改善 → 闸门无罪不动。
- ⚠️ 撞线注记：改/移除>30元闸门撞宪法§10.3，任何接线须主人裁决。

**建议3：T+1开盘缺口+5分钟VWAP反事实**
- gap 五桶（<-2%/-2~0/0~2%/2~4%/>4%），控引擎和vr120。高开>2~3%桶胜率显著低、盈亏比差，且30分钟VWAP反事实改善胜率/盈亏比、Top5%右尾保留≥95% → 模拟盘测"高开过滤/延迟成交"；VWAP改善但砍右尾 → 不接线。

**建议4：双引擎共识+ML校准诊断**
- 每日"双高/单高/分歧"标签统计未来20日胜率/盈亏比/超额；季度算 ml IC、分组单调性、校准曲线、行业/市值暴露。
- 判定分支：ml IC正常但分歧票拖累 → 只交易共识票；ml IC 2026转负而bp_ep稳 → 降ml权重（不换模型）；两者正常 → 回执行层。

**建议5（新增）：画像特征只做事后分层，不接线**
- 用已提取的53列特征/"涨停日×缩量"格子对2024-2026实际交易打标签，比较格内/格外胜率、盈亏比、右尾，按年样本外。
- 判定：格内 n<30 或增量不显著（FDR q>0.1）→ 不接线；即使显著也先影子组合20-40交易日。
- 定位：防止把观察级83%胜率（游资画像王者格）直接接线的过拟合防线。

## 三、样本外与多重检验协议（第三块）

- **阈值选择**：用2024-2025或先验桶（gap>2%、持有≤2天）；**2026 只验证一次**；若2026已用于诊断，最终验证留2026H2/未来模拟盘。本轮实测已用2026做显著性描述（未调阈值），后续判别树的阈值一律2024-2025选、2026只判一次。
- **多重检验**：18闸门×多桶用 Benjamini-Hochberg FDR q<0.1；收益序列按交易日（调仓批次）block bootstrap 避免序列相关。
- **样本量纪律**：报告 n 与最小可检测效应；n<100 时胜率差<5pp 不轻易下结论（本轮实测：n=104 时 MDE=19.4pp，为 n<100 结论边界提供了实锚）。
- **影子先行**：所有规则先影子组合并行 20-40 交易日，再谈接线。

## 四、主张细化与落地顺序（第三块）

**结论基调（据显著性实测下调力度）**：2026双杀不显著（CI重叠+PL含1），**不宜大改**；判别树降级为"只读诊断，预期增量有限但成本可控"；任何"改"动作的接线门槛不变（见下），但立项优先级按证据强度重排。

落地顺序（每步产出呈报后才进下一步）：

2. **P2 建议3缺口分层+VWAP反事实**（数据在库，零规则冲突，与P1并行可）。
3. **P3 建议2闸门消融+价格30断点**（只读统计；接线撞宪法§10.3须主人裁决）。
4. **P4 建议1卖出原因反事实**（依赖P1的L3层产物）。
5. **P5 建议4共识度+ml IC校准**（带10/8确认闸FAIL先例注记，预期保守）。
6. **P6 建议5画像事后分层**（最低优先级，纯防线性质）。

**"改"三件事（P1-P4 出证据后才动）**：①趋势卖出确认/最小持有（不延迟硬止损，撞裁决须批）；②闸门硬拒改排序惩罚/仓位缩放（撞§10.3须批）；③T+1高开/VWAP执行规则（模拟盘先行）。

**"躲"仅作风险预算**：若改后仍现"预测分歧度高+闸门通过率低+gap波动高"同时达历史高分位，总仓 100%→70% 降档，不方向性空仓；不用情绪档反向择时。

**接线门槛（任一不满足不接线）**：样本外胜率≥+2pp、盈亏比≥1.1、Top5%右尾保留≥95%、最大回撤不恶化、换手升幅≤20%。只提胜率但盈亏比仍<1 = 无效改进。
