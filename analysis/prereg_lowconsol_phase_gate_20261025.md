# PREREG#4: 低位横盘池效应·相位门假设 (2026-10-25)

> 性质: 研究验证(生产口径, 零交易权)。承接 prereg#3 §6 与 LOWCONSOL_PRODUCTION_SEMANTICS_GAP_20261025.md。
> 假设来源: 档案hyp2"主线首日2024+/熊市无效"注记 + 2026年翻负的按年分解 + 机制预判(低位补涨贝塔)。
> 理论驱动确认性检验(非扫参钓鱼); 通过后仍属**样本内结论**, 生产使用须前瞻影子期。

## 1. 假设

H-P: 低位横盘池效应(生产口径)为**相位条件化** — 牛市相位下显著为正, 弱势相位下消失/为负;
即 相位门(牛市才启用池)在历史上能恢复效应, 且2026年内的牛市相位子集是唯一可能仍有效的用法。

## 2. 口径(冻结, 与生产口径复验完全一致)

- 状态/事件/模拟: 全史加载(2019+) pos250真250日窗口; 事件=is_A全日+dpos冷却5; 
  t20e=收盘入场×0.92止损/T+20收盘; 宇宙6/0/3且>60日; qfq-only(与生产扫描器一致, 不并退市库)。
- 双估计器: 全池加权(pooled) + 每日≤20等权(cap20, seed42)。
- **相位定义(先验冻结, 一主一辅, 不扫参)**:
  - 主: 全宇宙等权指数(日均chg累乘) 收盘 > 其MA60 → 牛市相位
  - 辅: 全市场20日成交额分位 ≥ 0.5(扫描器自带探索开关口径)
- 事件相位 = 信号日相位。

## 3. 通过/证伪线(冻结)

- 主判定(2020-01~2026-10聚合, pooled): 牛市相位效应 ≥ +2.0pp **且** 牛-熊差 ≥ +1.0pp → PASS_PHASE_GATE
- 辅披露: cap20口径同向性; 分年(2024/2025/2026YTD/近250日)牛市子集效应全表。
- **决策项(无通过线, 只披露)**: 2026YTD牛市子集效应符号 — 若≤0, 结论为"相位门在当前市场无法激活该池",
  池继续停用; 若>0, 可进入"重新prereg+前瞻影子期"讨论, 仍非生产接线。
- 反向义务: 若牛市相位效应 < +2pp 或牛熊差反转 → 相位假设证伪, 该池整体归档为"相位无关且已衰减"。

## 4. 已知局限

相位定义与通过线为先验但历史全样本即拟合样本; MA60参数未扫参(60为常规约定);
等权指数非真实可投指数; 结论如需生产化必须前瞻影子期, 样本内通过不构成接线理由。


## 5. 结果记录(2026-10-25运行, lowconsol_phase_gate_20261025.py/json)

- 主判定(趋势牛市门, pooled聚合2020+): **FALSIFIED** — 牛市子集效应+4.02pp(≥2.0✓)
  但牛熊差**-5.27pp**(要求≥+1.0✗), 且逐年反向一致: 2024 -10.96 / 2025 -18.71 / 2026YTD -21.94pp。
  即: **牛市相位中触发的事件胜率反而系统性更低**("指数走强时仍未涨的滞涨弱票"), 假设方向反了。
- 决策项落地: 2026YTD牛市子集效应 **-1.56pp ≤ 0** → 相位门无法在当前市场激活该池, 池继续停用。
- 探索性新发现(样本内描述, 未验证, 禁直接使用): ①弱势相位触发的事件胜率逐年更高
  (2025熊中回调期事件胜率77.2%, 2026弱势期47.98% vs 牛势期26.04%) — "市场回调期入池"方向;
  ②辅相位(活跃度门amt_q≥0.5)在有双相数据的年份交互为正(2024 +4.17pp; 2026YTD +2.49pp)。
