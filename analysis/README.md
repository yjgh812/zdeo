# analysis/ — 分析类产物标准目录

> 铁律来源：所有文件禁止放 C 盘（含桌面），一律放 D:\zcodesj 下。
> 2026-09-22 桌面「分析板块」「股票信息」违规空文件夹事件后，主人确认建立本标准结构。

## 目录规范

| 目录 | 用途 | 命名建议 |
|------|------|----------|
| `板块分析/` | 行业/概念板块分析报告、榜单、截图 | `板块_<板块名>_<YYYYMMDD>.md/csv/png` |
| `持仓档案/` | 当前持仓个股全息档案(stock_dossier.py --holdings 生成) |
| `股票信息/` | 个股资料、基本面摘录、验证单附件 | `<代码>_<名称>_<YYYYMMDD>_<主题>.md/csv` |

## 使用规则

1. **任何会话**（知微、并行会话、定时链）产出分析类文件，一律写入本目录对应子目录，禁止建到桌面或其他 C 盘位置。
2. 需要新的主题子目录时，直接在 `analysis/` 下新建（如 `analysis/策略对比/`），并在本 README 补一行用途说明。
3. 临时/中间文件放 `D:\zcodesj\tmp\`，不放入本目录；正式报告类仍按惯例放 `D:\zcodesj\reports\`（两者不冲突：reports=系统定时链正式报告，analysis=交互会话分析产物）。
4. 文件名必带日期（YYYYMMDD），股票类必带「代码_名称」（代码必带名称铁律）。
