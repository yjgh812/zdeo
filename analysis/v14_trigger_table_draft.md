# 三段式流水线触发条件表（V14 参考件，非宪法修改）

> 宪法§12 修正草案——供主人裁夺后由主人或授权会话落入 AGENTS.md。
> 本件只呈草案文本，不直接修改宪法文件（owner=主人 §17）。

## 必走三段式（m1供数→m2/m4/m6分析→m7校验）条件

| 条件 | 说明 |
|---|---|
| 策略立项/复活 | 任何新信号源或已证伪策略的重启 |
| 回测验收 | 全域回测/窗口版回测的标尺比对 |
| 数据合同变更 | 数据表结构/PIT口径/备源链变更 |
| 卖出链动作 | 止损/止盈/信号退出制涉及卖出决策 |
| 闸门语义修改 | R闸新增/退役/阈值变更 |

## 可单agent直跑条件（m7事后抽查补位）

| 条件 | 说明 |
|---|---|
| 纯呈现报告 | 复盘/归因/晨报/夜报（零交易权已确立的呈现层） |
| 只读巡检 | health_check/freshness/DB新鲜度等已有探针 |
| 既定tool调用 | 已有命令的幂等重跑（如 registry 重跑） |
| 已批准批量执行 | 主人已裁决的批量动作执行（如 prereg影子日更） |

## 触发条件表落位建议

建议以本表正文替换宪法 §12 第二段「优先多 agent…只在任务能拆成互不干扰的独立域时使用」，使触发条件从原则性表述升级为可执行判定表。
