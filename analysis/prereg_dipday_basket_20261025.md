# PREREG#6: 市场急跌日×低位股篮子 假设检验 (2026-10-25)

> 性质: 研究验证(零交易权)。动机: 主人模拟盘个股层实证——10-19市场急跌日09:30篮子买入的
> 3只低位股(中电港+7.3%/中文在线+4.0%/飞南资源+1.0%)为账户全部大赢家;
> 此假设(市场级触发×横截面低位)与已证伪假设(个股级追高/朴素回调/主线过滤)均不同构, 属未测空白。
> 多重检验声明: 本假设在同一段2020-2026历史上已是第N次检验, 任何阳性结果仅具假设生成价值,
> 不得直接使用; 通过则登记前瞻队列, 以未来样本裁决。

## 1. 假设

H-DIP: 市场急跌日(等权指数单日收益≤-2%)买入低位股篮子(pos250<30, 过硬闸),
T+1开盘入场, 其后收益显著优于 ①平常日的同款低位篮子(急跌日的增量) ②急跌日的全宇宙(低位的增量)。

## 2. 口径(冻结)

- 等权指数: 全宇宙(6/0/3,>60日)逐日change_pct等权均值累乘。急跌日 = 单日等权收益 ≤ -2%。
- 篮子: 当日通过硬闸(close≤30/非ST/20日均额≥3000万/volume>0)且 pos250<30(rolling250,min120) 的全部股票, 等权。
- 执行: T+1开盘入场(无前视; T+1开盘缺失的股票剔除), 出场=T+5/T+10/T+20收盘(缺失剔除)。
- 分析单元: **日**(每日篮子均值收益为一个样本), 非个股——回答"急跌日该不该买篮子"。
- 窗口: 2020-01-04~2026-10-23; 分半: 2020-2022H / 2023-2026H 稳健性。

## 3. 四格矩阵(冻结)

| Cell | 触发日 | 篮子 |
|---|---|---|
| A | 急跌日 | 低位股 |
| B | 急跌日 | 全宇宙(过闸全部) |
| C | 平常日(非急跌) | 低位股 |
| D | 平常日 | 全宇宙 |

主对照: A vs C(急跌日增量); 次对照: A vs B(低位增量); D为总基线。

## 4. 通过/证伪线(冻结)

- 急跌日数 ≥ 30(样本充分);
- T+10口径: A均值 − C均值 ≥ +1.0pp 且 A均值 − B均值 ≥ +0.5pp;
- 分半(2020-22H / 2023-26H)两半 A−C 方向一致为正;
- 三条全满足 → PASS(登记前瞻队列); 任一不满足 → FALSIFIED(主人账户赢家模式定性为
  "相位运气+砍亏纪律", 非可重复的急跌日选股优势)。
- 披露项: 按趋势相位(MA60牛/熊)分层的A/C表现; T+5/T+20全表。

## 5. 已知局限

等权指数非可投指数; 急跌日-2%阈值为先验单点(不扫参); 未含交易成本;
T+1开盘入场比主人盘中抄底口径更保守(其买入时点不可回测, 如实声明)。

## 6. 结果记录(2026-10-25运行, dipday_basket_test_20261025.py/json)

- 判定: **FALSIFIED**(按冻结线) — 急跌日增量A−C=+0.87pp(<1.0线); 低位增量A−B=**-0.04pp**(<0.5线)。
  127个急跌日, 分半A−C=[+0.58,+1.10]方向一致但幅度不达标。
- **拆解发现(登记为前瞻候选, 非注册主判)**:
  - 低位过滤零增量: 急跌日A(低位篮)≈B(全宇宙篮)各期几乎相等(T+20: 2.69% vs 2.83%);
    平常日C≈D同样相等 → **pos250<30筛选在该收益族中不提供任何增量**;
  - **急跌日本身是真信号**: B−D(同为全宇宙, 急跌日vs平常日): T+5 +1.11pp / T+10 +0.91pp /
    T+20 **+1.80pp**(2.83% vs 1.03%, 胜日58.4% vs 54.7%) — 127日样本, 效应稳定。
- 解读: 主人10-19赢家篮子的超额来自**急跌日时机**(B−D), 不来自低位选股(A−B≈0);
  "深跌急买"有效, 但"深跌日买什么"在流动性闸内几乎不重要。
- 前瞻队列登记: 急跌日触发的下一开盘买入(篮子构成=任意过闸股, 无低位条件) — 与弱势相位
  假设(周粒度)互补的日粒度触发器; 样本外验证前不得使用。
