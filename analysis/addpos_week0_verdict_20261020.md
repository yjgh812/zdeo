## 二、结果解读（事实与限制物理隔离）

1. **R0 基线本身处于失效窗**：2025-2026 合并窗胜率仅 30.89%（退出结构：rebalance 76 / end_of_sample 24 / stop_loss 23）——与 10/19 定谳的"2026 双引擎 regime 失效年"一致。**在信号体系失效的 regime 窗，加仓任何结构都无正增量**，与 deep study 六派零分歧第⑥条"只在趋势行情加仓"互证：加仓的价值前提（趋势环境）在本窗不存在。
2. **机械形态自洽**：止损越高的臂越早出局（R1 上移止损 20.3% < R2 27.6% < R3 摊平止损最远 29.3% ≤ R0 30.9%）——在下行路径主导的窗里，"合法结构"（加仓即抬止损）反而放大了提前退出频率。这不是对合法判别式的否定，而是该窗无趋势的又一证据。
3. **已知口径局限（不改变结论方向，但须随结论携带）**：①叠加臂的 stop0=entry×0.92 为本实验引入的近似（R0 的 23 笔 stop_loss 由模板引擎语义退出，两口径未必逐位一致），系统性压低叠加臂胜率；②日频近似（low 破线→次日开盘出）与加仓次日开盘成交近似；③费率用 0.13% 双边近似。R1/R2 距达标差距（-12.6pp/-5.3pp）远超口径噪声量级，结论方向稳健。
4. R3 盈亏比 0.924 与 R0 0.921 基本持平、中位略好——摊平在失效窗"看起来没那么糟"恰是摊平的数学陷阱（拉低混合成本使正收益更易达成），与六派"绝不摊平"判负结论不矛盾。

## 三、结论与后续

**负结论（按方案停止规则）：当前信号体系下，规则加仓（合法结构 R1/R2 与判负对照 R3）在 2025-2026 样本外全部无正期望，深度学习加仓的前置条件不成立，加仓项目终止。** 若未来 regime 修复（B3 重启条件三信号在案）且信号体系恢复正期望，加仓议题重启时须引用本报告并重跑 Week-0。
