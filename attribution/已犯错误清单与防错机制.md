## 二、防错Checklist（每次回测/归因前逐项检查）

### 回测前Checklist

```
□ V1-数据预检：运行 precheck_data()，确认verdict=PASS？
□ V1-数据源：是否使用qlib bin（非meta db 2024-2025）？
□ V1-异常值：是否过滤|涨跌幅|>50%和gap>15%的除权/错误数据？

□ V2-试验计数：本次共测试了多少个策略变体？N=？
□ V2-DSR计算：是否准备了收益序列供require_dsr()使用？
□ V2-措辞预审：结论是否准备标注DSR值和置信度标签？

□ V3-数据泄露：筛选/过滤条件是否使用了当日未来信息？
□ V3-交叉验证：是否有第二个数据源或OOS计划？

□ 代码必带名称：输出中股票代码是否标注名称？
□ 文件路径：输出文件是否放在 D:\zcodesj\ 下？
```

### 归因前Checklist

```
□ 数据口径：使用的价格/收益指标是否是正确口径？
□ 计划核对：是否读取了交易计划，确认操作是否计划内？
□ C4对称测试：如果盈亏取反，归因结论是否仍然成立？
□ 未来信息：归因是否仅使用交易时点可得的信息？
```

### 结论输出Checklist

```
□ DSR标注：是否附带了DSR值和置信度标签（✅/🟡/⚠️/❌）？
□ 局限说明：是否标注了样本量、数据源、已知局限？
□ 诚实拆分：事实与观点是否拆分？是否有"待验证"标注？
□ 措辞约束：DSR<0.90是否避免了"确认/上线/显著"等词？
```

## 三、验证纪律工具包使用指南

### 文件位置
`D:\zcodesj\attribution\validation_gate.py`

### 快速使用

```python
from validation_gate import precheck_data, require_dsr, verdict_label

# Step 1: 数据预检
check = precheck_data('qlib_bin')
if check['verdict'] != 'PASS':
    print(f"⚠️ 数据不可用: {check['reason']}")
    # 必须切换数据源或修复后才能继续

# Step 2: 回测...
# returns = [...]
# n_trials = 本次测试的变体数

# Step 3: DSR检验
dsr_result = require_dsr(returns, n_trials=12)
print(f"DSR={dsr_result['dsr']}, {dsr_result['verdict']}")

# Step 4: 结论标签
label, allowed_phrasing = verdict_label(dsr_result['dsr'], direction='positive')
print(f"结论: {label}")
print(f"允许措辞: {allowed_phrasing}")
```

## 四、认知纠偏记录

| 偏差类型 | 表现 | 纠偏方法 |
|----------|------|---------|
| **Confirmation bias** | 只看支持结论的数据 | C4对称测试+找反例 |
| **数据可得性偏见** | 用现成字段当正确口径 | 口径校验+原始数据验证 |
| **结果导向偏差** | 用结果倒推过程质量 | 盈亏取反重跑归因 |
| **Multiple testing** | 测多个选最好的 | DSR校正+试验计数 |
| **过拟合** | 参数调到历史最优 | OOS验证+稳健参数区间 |
| **数据泄露** | 用当日信息筛当日标的 | 严格区分t-1/t信息 |
