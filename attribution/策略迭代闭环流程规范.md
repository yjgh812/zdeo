# 策略迭代闭环流程规范（屠龙系统×Qlib适配）

> 版本：v1.0 | 日期：2026-08-10 | 编制：知微
> 适用范围：屠龙系统盈亏归因→经验库→策略优化→回测验证→上线 全链路

---

## 一、闭环总览

```
盘后归因 → 经验入库 → 规律提炼 → 策略优化 → Qlib回测验证 → 上线/驳回
    ↑                                                        ↓
    └────────────── 实盘执行反馈 ←─────────────────────────────┘
```

**核心原则**：任何规则变更必须经过回测验证才能上线；禁止凭单笔交易结果修改核心规则。

---

## 二、每日归因流程（T日盘后 → T日20:00前）

### 2.1 自动化归因步骤

| 步骤 | 动作 | 产出 | 责任 |
|------|------|------|------|
| D1 | 盘后扫描westock模拟盘当日成交记录 | 原始交易列表 | 自动 |
| D2 | FIFO配对（BUY↔SELL），重构已平仓持仓 | position_history更新 | 自动 |
| D3 | 对每笔已平仓交易运行 `batch_attribution.py` | trade_attribution写入 | 自动 |
| D4 | 检查是否命中经验库已有案例模式 | 匹配标记 | 自动 |
| D5 | 新案例入库（如有） | experience_library更新 | 自动 |
| D6 | 输出《当日归因简报》 | 日归因摘要 | 知微 |

### 2.2 当日归因简报模板

```markdown
## T日归因简报
- 新增平仓：N笔（胜M负K）
- 当日归因分布：执行X% / 选股Y% / 市场Z% / 风控W%
- 命中已有案例模式：[案例ID列表]
- 新增失效场景：[如有]
- 明日关注：[风控提醒]
```

### 2.3 每日检查清单

- [ ] 所有已平仓交易是否完成归因
- [ ] 是否有止损线被突破（-8%）未触发卖出
- [ ] 是否有持仓超过设定周期上限
- [ ] 当日是否有计划外交易（非AB竞价路径）
- [ ] 护盾规则（持仓数/仓位比例）是否合规

## 三、每周深度反思（周五盘后）

### 3.1 周度归因聚合

| 步骤 | 动作 | 产出 |
|------|------|------|
| W1 | 汇总本周所有归因记录 | 周归因统计表 |
| W2 | 按4维度统计频次和金额占比 | 维度分布图 |
| W3 | 提炼高频问题TOP3 | 根因排序 |
| W4 | 对照经验库，检查是否出现新模式 | 新模式标记 |
| W5 | 提出优化建议草案（需回测验证） | 优化提案 |

### 3.2 周度优化提案格式

```markdown
### 优化提案 W-YYYYWW
- 触发归因：[本周高频问题]
- 提案内容：[具体规则调整]
- 预期效果：[定量预估]
- 验证方式：Qlib回测（区间/基准/指标）
- 状态：⏳ 待回测
```

### 3.3 周度经验库维护

- 检查经验库中规律的**时效性**：滚动4周窗口，若某类规律命中率<50%，标记降级
- 对新出现的失效场景，补充判定指纹和对应过滤规则
- 更新亏损案例库（选取本周代表性案例TOP3）

## 五、Qlib回测验证标准

### 5.1 回测验证流程

```
优化提案 → Qlib回测（近3年） → 对比基准 → 通过/驳回 → 上线/归档
```

### 5.2 通过标准（全部满足方可上线）

| 指标 | 要求 | 说明 |
|------|------|------|
| 年化收益率 | ≥基准+2% | 基准=优化前策略 |
| 最大回撤 | ≤基准+3pp | 不放大风险 |
| 夏普比率 | ≥基准 | 风险调整后收益不降 |
| 胜率 | ≥基准 | 选股准确度不降 |
| 月度胜率 | >50% | 月频稳定性 |
| 样本外验证 | 核心指标不衰减50%+ | 防过拟合 |

### 5.3 驳回规则

- 优化后年化收益反而下降 → 直接驳回
- 优化后最大回撤放大超5pp → 直接驳回
- 样本内外差异>50% → 标记过拟合风险，驳回或降级使用
- 交易频次大幅上升（>2倍） → 考虑滑点成本后重新评估

### 5.4 回测报告要求

```markdown
### Qlib回测验证报告
- 规则变更：[R-编号] [描述]
- 回测区间：YYYY-MM-DD ~ YYYY-MM-DD
- 基准策略：[版本号]
- 核心指标对比：[表格]
- 样本外验证：[结果]
- 结论：✅通过 / ❌驳回 / ⚠️有条件通过
- 上线版本：[新版本号]
```

## 六、经验库调用规则

### 6.1 选股前置过滤（每日AB候选生成时）

```
候选标的 → 匹配「失效场景库」 → 命中6指纹 → 剔除
          → 匹配「大跌风险库」 → 命中高风险标签 → 降权/剔除
          → 匹配「盈利范式库」 → 命中能力型特征 → 加权
```

### 6.2 规律时效性管理

| 检查频率 | 检查内容 | 处理方式 |
|----------|----------|----------|
| 每周 | 近4周规律命中率 | <50%标记降级 |
| 每月 | 全量规律准确率 | <40%移出活跃库 |
| 每季度 | 经验库全面审计 | 清理过时规则 |

### 6.3 经验库与Qlib联动

- **因子权重优化**：每月基于归因结果，调整Qlib模型因子权重（强化有效因子、弱化失效因子）
- **特征工程**：经验库中新发现的 predictive 特征，纳入Qlib因子库
- **标签优化**：归因分类标签可作为Qlib多任务学习的辅助标签

## 七、极端行情专项机制

### 7.1 触发条件

- 全市场单日涨停>150家 → 启动涨停专项归因
- 全市场单日跌停>100家 → 启动跌停专项归因
- 持仓单日亏损>5% → 启动持仓专项复盘

### 7.2 专项归因产出

- 极端行情共性特征总结
- 仓位管理应对规则（加减仓阈值）
- 选股逻辑临时调整（仅当日有效，不改正式规则）
