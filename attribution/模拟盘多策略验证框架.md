## 二、交易记录DB扩展

在attribution.db新增 `verification_trades` 表：

```sql
CREATE TABLE IF NOT EXISTS verification_trades (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    trade_date TEXT NOT NULL,        -- 交易日期
    stock_code TEXT NOT NULL,        -- 股票代码
    stock_name TEXT,                 -- 股票名称
    strategy_id TEXT NOT NULL,       -- V1-V8 策略编号
    hypothesis TEXT,                 -- 本笔交易验证的假设
    entry_price REAL,                -- 买入价
    volume INTEGER,                  -- 数量
    signal_snapshot TEXT,            -- JSON: 买入时因子快照
    expected_outcome TEXT,           -- 预期结果（涨停/正收益/止损）
    actual_ret_t1 REAL,              -- T+1实际收益（回填）
    actual_ret_t3 REAL,              -- T+3实际收益（回填）
    actual_ret_t5 REAL,              -- T+5实际收益（回填）
    result TEXT,                     -- 验证结果：confirmed/refuted/inconclusive
    notes TEXT,
    created_at TEXT DEFAULT (datetime('now','localtime'))
);
```

## 三、每日交易流程

### 盘前（8:30-9:25）
1. 计算全市场因子（mom5/resvol20/动量分位）
2. 筛选各策略候选池：
   - V1低开承接：前日涨停+今日竞价低开2-4%
   - V2高动量：mom5>5%
   - V3高波高动量：rv20 Top10%+mom5>0
3. 分配各策略验证仓位（每个策略2-3只）

### 盘中（9:25-15:00）
4. 竞价结束后确定V1/V5的实际买入标的
5. 开盘后执行买入，记录signal_snapshot
6. 14:30检查持仓（止损/止盈）

### 盘后（15:00-16:00）
7. 回填当日交易的T+1收益
8. 回填3日/5日前交易的T+3/T+5收益
9. 更新各策略累计统计
10. 积累30+样本后做显著性检验
