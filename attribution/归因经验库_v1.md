## 五、归因方法论纠错案例（知微自身失误，防再犯）

### 纠错案例 #M1：嵘泰股份误判（2026-08-10 主人纠正）

| 字段 | 内容 |
|------|------|
| 案例ID | TL-META-20260810-001 |
| 错误结论 | "嵘泰 +254% 但自 52 周高点回落 51%，阶梯止盈早该触发，风控失守只减未清" |
| 错误原因 | ① **口径偷换**：52周最高价(51.79)≠持仓盈利峰值，阶梯止盈回撤基准是持仓成本对应的浮盈峰值；② **计划未读**：v3 计划明写"43.6%→5% 减仓腾资金"，归因前未读计划，把计划内动作误判为执行失误；③ **确认偏误**：先见亏损数字 -12,205 形成"有问题"预设，反向找证据（用了行情接口 -4.55% 而非持仓口径 -2.73%） |
| 正确结论 | 嵘泰减仓 = 计划内执行正确 ✅；今日 -2.73%（持仓口径） |
| **深层根因（同一认知机制两次投影）** | **结果导向偏差（Outcome Bias）**——用"今日亏损金额"这个**结果**倒推"过程有错"的结论，而非用"过程事实"评判过程质量。两个错误的统一解释：① 先见 -12,205 → 预设"有错" → 找最方便的数据（52周高）支撑 → 错误一；② 亏损大 → 认定"操作一定失守" → 未读计划即扣帽 → 错误二。**若当日 +12,205，这两个错误都不会发生**——结论完全由结果驱动，非过程驱动。次级机制：数据可得性偏见（现成字段≠正确口径）、时间框架错位（52周坐标评判单次持仓）、单维评判（盈亏金额≠操作质量）。 |
| 教训 | 归因者自身也会犯归因错误：数据可得性偏见（拿现成字段当正确口径）+ 结论先行 + 计划核对缺失 |
| 对应机制 | 《归因执行 checklist v1》：A 数据口径校验 / B 计划对照校验 / C 反确认偏误校验（**新增 C4 结果对称测试：盈亏取反重跑归因，结论若消失则归因被结果导向偏差污染**）/ D 报告输出规范 |
| 场景标签 | 归因方法论 / 口径混用 / 确认偏误 / 计划未读 / **结果导向偏差** / 结论先行 |
